# Торговый офис v3 — итог и карта (на русском)

Только демо-счёт Alpaca (paper). Реальные деньги не включаются нигде в коде. Лимиты не менялись: без плеча, без шортов и опционов, риск ≤ 2% на сделку со стопом, дневной стоп −5%, ≤ 5 входов в сутки, ≤ 3 позиции, ошибка или невалидный ответ → пропуск.

## Что умеет офис
1. **Исследовательский отдел** (работает постоянно, выводы в `board.db` с id): макро-аналитик (07:00 и за час до важных событий), календарь событий (за 30 минут до и после важного события USD новые входы запрещены), новости (каждый час, срочное — сразу в зал и в Telegram), крипто-аналитик (фандинг, открытый интерес, ликвидации — раз в час), секторы (раз в день), портфельный аналитик (раз в день и после каждой сделки), **«Картина дня»** (07:30 и каждые 4 часа; зал обязан сослаться на свежую, иначе отчёт отклоняется), память (выводы прошлых дней учитываются).
2. **Честный счёт и обучение:** 5 теневых портфелей (весь офис, S&P 500, биткоин, только технический анализ, только стратегии лаборатории); разбор каждой закрытой сделки с уроками; вес голоса по заслугам (меняется только после вашего «да»); проверка фактов Gemini + сверка цены двух источников.
3. **Умнее вход и выход:** режим рынка (тренд / боковик / высокая волатильность / паника), сопровождение позиций (безубыток, подтяжка стопа, половина на +3%, выход по времени 48 ч), «умные деньги» Hyperliquid, вероятности Polymarket, лаборатория с поправкой на множественное тестирование и 14-дневным испытанием.
4. **Управление с телефона:** команды `/статус /позиции /картина /отчёт /пауза /продолжить /закрыть <актив>`, вопросы обычным текстом, брифинг 08:00, сводка каждые 6 часов, вечерний отчёт 21:00, собрание по воскресеньям 20:00 (вопросы «да / да 1 / нет»).
5. **Надёжность:** IT-отдел (заряд < 20%, интернет, перезапуск лаборатории, режим экономии лимитов), сторож в cron, сообщение о том, сколько офис не работал, критерии перехода на реальные деньги (только отчёт).

## Команды Termux
```bash
cd ~/projects/trading_office

./office.sh start            # запустить офис и лабораторию
./office.sh status           # состояние
./office.sh log 60           # последние строки лога (или: ./office.sh log 60 lab)
./office.sh reload           # мягкий перезапуск без Termux-сессии (процессы перезапускают себя)
./office.sh restart          # полный перезапуск
./office.sh halt / resume    # пауза / снять паузу (то же, что /пауза и /продолжить в Telegram)
./office.sh stop             # остановить всё (сторож тогда не поднимает)
./office.sh once ONDO/USD --dry-run   # один актив, без ордера (живая проверка)

# экономия памяти: только офис, без лаборатории
touch NO_LAB && ./office.sh restart     # вернуть лабораторию: rm NO_LAB && ./office.sh restart

# сторож в cron (раз в 10 минут):
crond                                    # если cron не запущен
(crontab -l 2>/dev/null | grep -v office.sh; echo '*/10 * * * * /data/data/com.termux/files/home/projects/trading_office/office.sh watchdog') | crontab -
crontab -l
```

## Что важно знать
- Лаборатория после введения поправки: из 84 «рабочих» стратегий за сутки строгую проверку не прошла ни одна — прежние находки были в основном случайностью. Новые идут на 2 недели испытаний.
- Первый запуск после остановки: исследовательские отчёты строятся с нуля (первые 10–15 минут «Картина дня» может быть механической, с половинным размером позиций).
- Частичная продажа и замена стопа у **акций** (OCO) проверены только тестами с моками; у крипты замена стопа проверена вживую на paper-позиции ONDO.
- Ключи Alpaca/Telegram/GitHub были присланы в чат и лежат в `~/.claude.json` — рекомендуется перевыпустить (DECISIONS #11, #30).
