# DECISIONS — решения без вопросов (журнал)

| # | Решение | Почему |
|---|---|---|
| 1 | Исполнение всех 7 активов (AAPL, MSFT, NVDA, SPY, BTC/USD, ETH/USD, SOL/USD) — **Alpaca Paper** (REST из Python). Binance Testnet и собственный SimBroker в live не используются. | Указание владельца (гео-блок Binance). SimBroker остался только для бэктеста. |
| 2 | Торговые вызовы идут только через `AlpacaBroker` после `RiskGate`. alpaca-mcp-server подключён в `.mcp.json` для ручной работы человека (в Claude Code), оркестратор и агенты его НЕ используют. | LLM с доступом к create_order обошёл бы лимиты в коде. |
| 3 | Проверено живым вызовом: **crypto не поддерживает bracket/OTO** (`crypto orders not allowed for advanced order_class`). Крипта = market buy → сразу защитный `stop_limit` sell GTC (limit = stop −1%); если стоп не встал — позиция немедленно закрывается. Take-profit крипты исполняет бот (проверка на каждом цикле и в `watch`). Акции = настоящий bracket (whole shares, GTC). | Ограничение API Alpaca. |
| 4 | Данные для анализа: крипта — свечи Binance `data-api.binance.vision` + деривативы Hyperliquid; акции — Yahoo chart. Исполнение/цены ордеров — Alpaca. | Binance public data работает без ключей и даёт глубокую историю для бэктеста. |
| 5 | Аккаунт paper имеет margin x4, shorting и options разрешены. В коде: размер ≤ **cash** (не buying_power) → плечо 1x; ордера только `side=buy` для входа, `sell` только закрывает существующий лонг; опционов нет. | «cash, 1x, без шортов и опционов». |
| 6 | Риск: убыток до стопа **с учётом комиссии и проскальзывания** ≤2% эквити; нотионал ≤25%; ≤3 позиции; ≤5 входов/день (UTC); дневной стоп −5% от эквити на начало UTC-суток (блок новых входов; позиции остаются под защитными стопами). | Требования владельца + интерпретация «на сделку». |
| 7 | **Любая ошибка/невалидный ответ агента → пропуск цикла по активу** (ничего не торгуется, причина в журнале). Легитимное `abstain` (нет данных для роли) — не ошибка. | Требование владельца; per-asset, чтобы один сбой не блокировал управление остальными позициями. |
| 8 | Модели: analysts (tech, fundamental, news, onchain_derivs) — **Gemini** (REST, ключ из .env; цепочка `gemini-3.1-flash-lite` → `3.5-flash-lite` → `3.5-flash`: на free-tier у `3.5-flash` дневной лимит запросов исчерпался за пару вызовов (проверено, 429 PerDay), при дневной квоте код переходит на следующую модель; 4с между запросами, backoff на 429/503). bull, bear, trader, risk_manager, portfolio_manager, executor — **Claude** (`sonnet`; executor/journal — `haiku`) через `claude -p` без хуков/MCP/CLAUDE.md. | Требование владельца; флаги -p сокращают запуск с 83с/$0.06 до ~19с/$0.001. |
| 9 | Комиссии симулятора (бэктест): крипта 0.25% (базовый tier Alpaca, консервативно) + 0.05% проскальзывание; акции 0% + 0.05%. Стресс-прогон: проскальзывание 0.20%. | Alpaca: крипто-комиссии 15-25 bps, акции без комиссии. |
| 10 | Бэктест — rule-based роли (tech+derivs); LLM-роли в нём не участвуют (нет исторических новостей/фундаментала, look-ahead модели, стоимость). Результат = базлайн + проверка риск-пайплайна, не оценка LLM-фирмы. | Честность; см. PLAN.md. |
| 11 | Секреты только в `.env` (в .gitignore, chmod 600). Ключи были присланы в чате → после проекта рекомендуется перевыпустить. | Гигиена. |
| 12 | Аналитики (4 вызова Gemini × 7 активов × 6 циклов/сутки ≈ 170 запросов/день) могут упереться в free-tier. Если все модели цепочки исчерпаны → ошибка агента → по правилу #7 цикл по активу пропускается. Для продакшена нужен платный ключ или `--interval 8`. | Честное ограничение. |
| 13 | Telegram-кнопки: по умолчанию включены (`run/once` без `--auto`); таймаут 10 мин без ответа = отклонить. Без Telegram-кредов запуск без `--auto` отказывается стартовать. Рекомендован отдельный бот (`TG_TOKEN`/`TG_CHAT` в .env), т.к. getUpdates конфликтует с другим процессом на том же токене. | Безопасный дефолт. |
